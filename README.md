# 原資增能獎勵報到系統 (cip_fjuirc)

本專案為大會與研習專用之報到與統計查詢系統，前端由 GitHub Pages 託管，後端串接 Google 試算表 (Google Apps Script)。

- **線上系統網址**：[https://talented-fjcu.github.io/cip_fjuirc/](https://talented-fjcu.github.io/cip_fjuirc/)

---

## 📌 系統功能特點

1. **大會報到管理 (`index.html`)**：
   - **LINE / 手機相機掃描**：內建 HTML5 相機辨識引擎，工作人員使用手機開啟網頁並允許相機權限後，可直接掃描參加者身分證背面條碼 (Code 39) 或 QR Code。
   - **保留手動輸入**：完整保留身分證字號手動輸入框與確認報到按鈕。
   - **掃描報到顯示**：依主辦單位需求，畫面僅醒目顯示「**姓名**」、「**編號**」與「**報到成功**」，簡潔清晰無多餘干擾。
   - 具備防重複報到提示 (⚠️ 重複報到) 與成功「嗶」音效回饋。
   - 支援 4 秒自動重置清空，方便現場工作人員流暢連續掃描。

2. **研習統計看板 (`query.html`)**：
   - 即時統計總人數、已報到人數、未報到人數與交通費核銷總數。
   - 多維度自適應篩選：報到狀態 (已報到/未報到)、組別、獎勵項目、交通費核銷否。
   - 支援關鍵字即時模糊搜尋。

## 📊 試算表欄位結構 (固定 7 欄)

試算表第一列為標題列，系統嚴格依據下列 7 欄位依序讀寫：

| 欄位代號 | 欄位名稱 | 說明 |
| :---: | :--- | :--- |
| **A 欄** | **編號** | 學員或與會者序號 (如 001) |
| **B 欄** | **組別** | 分組資訊 (如 第一組) |
| **C 欄** | **身分證字號** | 系統比對鍵值 (自動大寫) |
| **D 欄** | **姓名** | 學員姓名 |
| **E 欄** | **獎勵項目** | 獲獎或表揚項目 |
| **F 欄** | **報到時間** | 系統掃描成功後自動寫入時間戳記 (`yyyy-MM-dd HH:mm:ss`) |
| **G 欄** | **交通費核銷否** | 交通費是否核銷 (`是` / `否`) |
